# CodeAlpha Secure Coding Review

**Task 3 | Python | Simple Login System**

This project reviews an intentionally insecure login program, identifies common security weaknesses, and demonstrates an improved educational version.

### Files
- `insecure_login.py` - code used for the security review
- `secure_login.py` - improved version
- `SECURITY_REVIEW.md` - findings and remediation
- `REPORT.md` - project report

### Main Topics
Hardcoded credentials, weak passwords, password hashing, login-attempt protection, and secure authentication practices.

**Note:** Educational project only; not production authentication software.
